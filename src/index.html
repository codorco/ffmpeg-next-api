Endpoints

POST /probe Inspecionar metadados de arquivo de mídia ▸

Retorna os metadados completos do arquivo — equivalente a ffprobe -of json -show_streams -show_format. Funciona com qualquer formato de mídia.

Exemplo
curl -F "file=@input.mov" HOST:PORT/probe

Resposta: JSON com streams e formato do arquivo.

POST /video/extract/audio Extrai faixa de áudio de um vídeo ▸

Retorna WAV mono por padrão.

Query params
ParamValoresPadrãoDescrição
monoyes / noyesno retorna todos os canais do original
Exemplos
# Mono (padrão)
curl -F "file=@input.mov" HOST:PORT/video/extract/audio > output.wav

# Todos os canais
curl -F "file=@input.mov" HOST:PORT/video/extract/audio?mono=no > output.wav
POST /video/extract/images Extrai frames de um vídeo como PNG ▸

Extrai frames do vídeo como PNG. Sem compressão, retorna JSON com URLs para download individual.

Query params
ParamValoresPadrãoDescrição
fpsnúmero1Frames por segundo a extrair (0.5 = 1 frame a cada 2s)
compresszip / gzip—Retorna todos os frames num único arquivo compactado
Exemplos
# 1 frame por segundo — retorna JSON com URLs
curl -F "file=@input.mp4" HOST:PORT/video/extract/images

# 2 frames por segundo
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?fps=2

# 1 frame a cada 2 segundos
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?fps=0.5

# ZIP com todos os frames
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?compress=zip > frames.zip

# tar.gz com todos os frames
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?compress=gzip > frames.tar.gz
Resposta JSON (sem compressão)
{
  "totalfiles": 3,
  "description": "Extracted image files and URLs to download them...",
  "files": [
    { "name": "abc123-0001.png", "url": "http://HOST:PORT/video/extract/download/abc123-0001.png" },
    { "name": "abc123-0002.png", "url": "http://HOST:PORT/video/extract/download/abc123-0002.png" }
  ]
}
GET /video/extract/download/:filename Baixa um frame extraído ▸

Baixa um frame extraído por /video/extract/images e o apaga do servidor por padrão.

Query params
ParamValoresPadrãoDescrição
deleteyes / noyesno mantém o arquivo no servidor após o download
Exemplos
# Baixa e apaga
curl HOST:PORT/video/extract/download/abc123-0001.png > frame.png

# Baixa sem apagar
curl HOST:PORT/video/extract/download/abc123-0001.png?delete=no > frame.png
POST /image/to/scroll-video Gera vídeo de scroll a partir de uma imagem longa ▸

Recebe uma imagem longa (ex: screenshot de página web), escala para a largura alvo e gera um vídeo MP4 com scroll suave de cima para baixo.

Query params
ParamPadrãoDescrição
velocidade180Velocidade do scroll em pixels/segundo
crf20Qualidade do vídeo: 0 = perfeito, 51 = pior
largura1080Largura do vídeo de saída em pixels
altura1920Altura da tela (viewport) em pixels
fps30Frames por segundo
Como funciona
  1. A imagem é redimensionada para a largura alvo mantendo a proporção.
  2. O percurso é calculado: altura_escalada − altura_tela.
  3. A duração é calculada: percurso / velocidade.
  4. O vídeo é gerado com um crop animado que percorre a imagem de cima a baixo.
Imagens com altura menor que a tela resultam em vídeo muito curto (percurso mínimo = 1px).
Exemplos
# Defaults (1080×1920, scroll 180px/s, CRF 20)
curl -F "file=@foto.jpg" HOST:PORT/image/to/scroll-video > scroll.mp4

# Scroll mais lento, qualidade máxima
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?velocidade=80&crf=15" > scroll.mp4

# 9:16 personalizado, 60fps
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?largura=1080&altura=1920&fps=60" > scroll.mp4

# Scroll rápido para preview
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?velocidade=400&crf=28" > preview.mp4
POST /image/to/images-to-video Cria vídeo a partir de múltiplas imagens ▸

Recebe N imagens via multipart/form-data (campo file repetido) e gera um vídeo MP4 onde cada imagem é exibida por igual tempo, totalizando exatamente totalDuration segundos.

Query params
ParamObrigatórioPadrãoDescrição
totalDurationsim—Duração total do vídeo em segundos
widthnão1920Largura em pixels
heightnão1080Altura em pixels
fpsnão30Frames por segundo
crfnão20Qualidade: 0 = perfeito, 51 = pior
scalenãocontainModo de ajuste da imagem (ver abaixo)
transitionnãofalsetrue adiciona fade suave entre imagens
Modos de escala
ValorComportamento
containImagem inteira visível com barras pretas nas bordas
coverImagem preenche o frame, pode cortar bordas
stretchImagem esticada para preencher exatamente (distorce)
fillImagem contida centralizada sobre fundo igual borrado (blur)
Lógica de tempo:
Sem transição: tempoPorImagem = totalDuration / N
Com transição: tempoPorImagem = (totalDuration + (N−1) × 0.5) / N
Limite: até 50 imagens por requisição. Tamanho máximo total: 512 MB.
Exemplos
# 5 imagens, 30s, 1080p, contain, sem transição
curl \
  -F "file=@img1.jpg" -F "file=@img2.jpg" -F "file=@img3.jpg" \
  -F "file=@img4.jpg" -F "file=@img5.jpg" \
  "HOST:PORT/image/to/images-to-video?totalDuration=30&width=1920&height=1080" \
  > slideshow.mp4

# 4 imagens, 20s, 9:16 (reels), cover, com fade
curl \
  -F "file=@img1.jpg" -F "file=@img2.jpg" -F "file=@img3.jpg" -F "file=@img4.jpg" \
  "HOST:PORT/image/to/images-to-video?totalDuration=20&width=1080&height=1920&scale=cover&transition=true" \
  > reel.mp4

# 3 imagens, fundo borrado, alta qualidade
curl \
  -F "file=@img1.png" -F "file=@img2.png" -F "file=@img3.png" \
  "HOST:PORT/image/to/images-to-video?totalDuration=15&scale=fill&crf=15&transition=true" \
  > video.mp4

wordsPerLine — Palavras por tela

Controla quantas palavras aparecem por bloco de legenda. Útil quando o arquivo de entrada tem muitas palavras por linha.

ValorComportamento
0 ou omitidoSistema decide (comportamento padrão, sem divisão)
1Uma palavra por vez
4Máximo 4 palavras por bloco
NMáximo N palavras por bloco
Para arquivos ASS com karaoke (\k tags): o tempo de cada grupo é recalculado com base na duração real das sílabas — o karaoke continua preciso. Para SRT e texto puro: o tempo do bloco original é distribuído proporcionalmente.
ASS sem estilos — configuração automática

Quando o arquivo .ass não possui uma seção [V4+ Styles], a API injeta automaticamente o estilo gerado a partir do config do request.

Isso permite manter o arquivo .ass com apenas os timings e tags de karaoke, delegando toda a aparência visual ao config.

Chave karaokeEfeito no estilo ASS
karaoke.textColorCor do texto ainda não falado (SecondaryColour)
karaoke.highlightColorCor da palavra ativa no momento (PrimaryColour)
Se o .ass já tiver [V4+ Styles], ele é usado diretamente sem modificação.

POST /video/add/audio Adiciona e mistura trilhas de áudio em um vídeo ▸

Recebe um vídeo e até 5 trilhas de áudio. A API monta automaticamente todos os filtros FFmpeg com base em um JSON de configuração. Ideal para YouTube, Shorts, Reels, TikTok, Instagram e automações via n8n.

Campos multipart
CampoTipoObrigatórioDescrição
videoarquivosimVídeo de entrada (mp4, mkv, mov, webm, avi…)
track0…track4arquivonãoTrilhas de áudio (mp3, wav, aac, ogg…)
imagearquivonãoImagem para afterVideo.mode="image"
configtextonãoJSON de configuração (padrões se omitido)
Estrutura do config JSON (todos os campos opcionais)
{
  "mode":          "mix",
  "originalAudio": "keep",
  "duration":      "video",
  "normalize":     false,
  "crossfade":     0,

  "ducking": {
    "enabled":     false,
    "voiceTrack":  0,
    "musicTrack":  1,
    "musicVolume": 0.20
  },

  "afterVideo": {
    "mode":     "freeze",
    "color":    "black",
    "image":    null,
    "duration": "audio"
  },

  "tracks": [
    {
      "volume":       1.0,
      "delay":        0,
      "loop":         false,
      "mute":         false,
      "fadeIn":       0,
      "fadeOut":      0,
      "playbackRate": 1.0,
      "trim": { "start": 0, "end": null }
    }
  ]
}
mode — modo de mixagem
ValorComportamento
mix (padrão)Mistura todas as trilhas em um único stream de áudio
streamsCada trilha fica como stream independente no container (selecionável pelo player)
originalAudio — áudio original do vídeo
ValorComportamento
keep (padrão)Mantém o áudio original e mistura com as trilhas
removeRemove completamente o áudio original
muteInclui o áudio original com volume 0 (silenciado)
duration — controle de duração
ValorComportamento
video (padrão)O vídeo determina a duração — áudio maior é cortado
audioO áudio determina a duração — use afterVideo para estender o vídeo
longestUsa a maior duração entre vídeo e áudio
shortestUsa a menor duração entre vídeo e áudio
afterVideo — o que exibir quando o vídeo terminar

Usado quando duration é "audio" ou "longest" e o áudio é mais longo que o vídeo.

modeComportamento
freezeCongela o último frame do vídeo
colorTela sólida com a cor informada em color (ex: "black", "#1a1a1a")
imageExibe a imagem enviada no campo image

O campo afterVideo.duration pode ser "audio" (calcula automaticamente) ou um número em segundos.

Configuração por trilha (tracks[i])
CampoPadrãoDescrição
volume1.0Volume: 0 = silêncio, 1 = original, 2 = dobro
delay0Atraso para iniciar a trilha (milissegundos)
loopfalseRepetir automaticamente a trilha até o fim do vídeo
mutefalseIgnorar esta trilha sem removê-la da configuração
fadeIn0Duração do fade in em segundos
fadeOut0Duração do fade out em segundos
playbackRate1.0Velocidade de reprodução: 0.5–2.0
trim.start0Início do recorte em segundos
trim.endnullFim do recorte em segundos (null = até o fim)
ducking — redução automática de volume

Quando a trilha de voz estiver ativa, a música reduz automaticamente o volume.

CampoPadrãoDescrição
enabledfalseAtiva o ducking
voiceTrack0Índice da trilha de voz (track0 = 0)
musicTrack1Índice da trilha de música a ser reduzida
musicVolume0.20Volume da música durante a fala (0.0–1.0)
Exemplos

Adicionar 1 áudio com controle de volume

curl \
  -F "video=@video.mp4" \
  -F "track0=@audio.mp3" \
  -F 'config={
    "originalAudio": "remove",
    "tracks": [
      { "volume": 0.8 }
    ]
  }' \
  HOST:PORT/video/add/audio > output.mp4

3 áudios com volume e fade

curl \
  -F "video=@video.mp4" \
  -F "track0=@narracao.mp3" \
  -F "track1=@musica.mp3" \
  -F "track2=@efeito.mp3" \
  -F 'config={
    "originalAudio": "remove",
    "tracks": [
      { "volume": 1.0, "fadeIn": 0.5, "fadeOut": 1.0 },
      { "volume": 0.4, "loop": true, "fadeIn": 2.0, "fadeOut": 3.0 },
      { "volume": 0.7, "fadeIn": 0.2, "fadeOut": 0.5 }
    ]
  }' \
  HOST:PORT/video/add/audio > output.mp4

Adicionar música de fundo com loop

curl \
  -F "video=@video.mp4" \
  -F "track0=@musica.mp3" \
  -F 'config={"tracks":[{"volume":0.3,"loop":true}],"originalAudio":"keep"}' \
  HOST:PORT/video/add/audio > output.mp4

Narração + música de fundo com ducking

curl \
  -F "video=@video.mp4" \

POST /convert/video Transcodificação profissional de vídeo ▸

Converte qualquer vídeo suportado pelo FFmpeg para qualquer outro container, com controle total sobre resolução, orientação, resize/fundo, codec/qualidade/preset/fps/color space/HDR/rotação/flip de vídeo, codec/bitrate/canais/sample rate/remoção de áudio e metadata — tudo via JSON, sem precisar conhecer flags do FFmpeg. Substitui o antigo /convert/video/to/mp4 (fixo, sem opções).

Fontes de entrada (escolha exatamente uma)

POST /convert/audio Converte áudio para qualquer formato suportado ▸

Converte qualquer áudio suportado pelo FFmpeg para qualquer outro formato de saída, com controle de qualidade ou tamanho máximo do arquivo. Substitui os antigos /convert/audio/to/mp3 e /convert/audio/to/wav (fixos, sem opções). Mesmas fontes de entrada, formatos de request e convenção de resposta de /convert/video (veja acima): multipart (arquivo audio, ou campos texto base64/url/localFile + config) ou application/json.

format — formato de saída

mp3, wav, aac, m4a, flac, ogg, opus, wma, aiff. Padrão: mp3. O codec é definido automaticamente pelo formato — não existe um campo de codec separado.

quality — qualidade / tamanho
ModoExemploDescrição

maxSize{"mode":"maxSize","value":10}Tamanho máximo do arquivo final, em MB — mesmo cálculo automático de bitrate usado em video.quality.mode="maxSize" do /convert/video. Não se aplica a formatos sem perdas
Headers de resposta

X-Original-Format, X-Output-Format, X-Audio-Codec, X-Audio-Quality, X-Output-Duration, X-Warnings.

curl \

POST /convert/image Converte e processa imagens ▸

Endpoint genérico de conversão/processamento de imagens. Substitui o antigo /convert/image/to/jpg (fixo). Mesma arquitetura de /convert/video e /convert/audio — só FFmpeg, sem biblioteca de imagem separada — com as mesmas 4 fontes de entrada e o mesmo transporte duplo JSON/multipart. O campo multipart do arquivo principal é file (igual aos outros endpoints simples desta API), com um campo opcional watermark para a marca d'água.

format é a única configuração obrigatória — pode vir como query param (?format=jpg, a forma mais simples) ou dentro do config JSON. Todo o resto é opcional e o padrão é "não alterar nada além do formato": sem resize, sem crop, sem watermark, sem rotação, sem flip, sem compressão adicional. O formato de entrada é sempre detectado automaticamente pelo conteúdo do arquivo (nunca pela extensão).

Formatos de saída suportados

jpg, jpeg, png, webp, avif, bmp, gif, tiff, tif, ico, ppm, pgm, pbm.

svg não é oferecido de propósito — é um formato vetorial e o FFmpeg não tem codificador de rasterização para ele; pedir svg retorna um erro explicando isso. webp e avif dependem do build do FFmpeg ter libwebp/libaom-av1 compilados — se faltar, o próprio FFmpeg retorna um erro claro de codec não encontrado.
Estrutura do config JSON
{
  "format": "jpg",
  "quality": 85,
  "compression": { "maxSize": "1MB", "targetReduction": 50, "allowResolutionReduction": false },
  "resize": { "percentage": 50, "maxWidth": 1920, "maxHeight": 1080, "width": 1200, "height": 800, "resizeMode": "contain" },
  "rotation": 90,
  "flip": "horizontal",
  "crop": { "aspectRatio": "1:1" },
  "watermark": { "file": "logo.png", "position": "bottom-right", "size": 20, "opacity": 1.0 }
}

CampoValoresPadrãoDescrição
quality1–10085Só para jpg/webp/avif (únicos com controle de qualidade real). Ignorado (com aviso) nos demais
compression.maxSize"500KB", "1MB", "5MB", "20MB"—Busca binária de qualidade (até 6 tentativas, nunca em loop infinito) pelo maior valor que ainda cabe no tamanho pedido. Tem prioridade sobre targetReduction

A meta de tamanho é tratada como objetivo, não garantia matemática — se realmente não for possível sem degradar demais, a API retorna o melhor resultado possível junto de um aviso em X-Warnings, nunca um arquivo quebrado.

Ordem de processamento

rotação → flip → crop → resize → watermark → compressão → exportação — o crop sempre atua sobre os pixels em resolução plena antes de qualquer redução, evitando perda de qualidade desnecessária.

Headers de resposta

X-Original-Format, X-Output-Format, X-Original-Size, X-Output-Size, X-Size-Reduction-Percent, X-Original-Resolution, X-Output-Resolution, X-Rotation-Applied, X-Watermark-Applied, X-Crop-Applied, X-Warnings.

  HOST:PORT/convert/image > output.jpg

12–13. Rotação e espelhamento

# Rotação 90°
curl -F "file=@input.jpg" -F 'config={"format":"jpg","rotation":90}' \
  HOST:PORT/convert/image > output.jpg

# Espelhamento horizontal
curl -F "file=@input.jpg" -F 'config={"format":"jpg","flip":"horizontal"}' \
  HOST:PORT/convert/image > output.jpg

14–17. Watermark: posição, centralizada, transparência, customizada

# Canto inferior direito (padrão)
curl -F "file=@input.jpg" -F "watermark=@logo.png" \
  -F 'config={"format":"jpg","watermark":{"position":"bottom-right"}}' \
  HOST:PORT/convert/image > output.jpg

# Centralizada
curl -F "file=@input.jpg" -F "watermark=@logo.png" \
  -F 'config={"format":"jpg","watermark":{"position":"center"}}' \
  HOST:PORT/convert/image > output.jpg

# Com transparência (50%)
curl -F "file=@input.jpg" -F "watermark=@logo.png" \
  -F 'config={"format":"jpg","watermark":{"position":"bottom-right","opacity":0.5}}' \
  HOST:PORT/convert/image > output.jpg

# Posição customizada (x,y em pixels)
curl -F "file=@input.jpg" -F "watermark=@logo.png" \
  -F 'config={"format":"jpg","watermark":{"position":"custom","x":100,"y":200,"size":15}}' \
  HOST:PORT/convert/image > output.jpg

18–21. Crop por proporção — 1:1, 4:5, 16:9, 9:16

# Quadrado 1:1
curl -F "file=@input.jpg" -F 'config={"format":"jpg","crop":{"aspectRatio":"1:1"}}' \
  HOST:PORT/convert/image > output.jpg

# Retrato 4:5 (Instagram)
curl -F "file=@input.jpg" -F 'config={"format":"jpg","crop":{"aspectRatio":"4:5"}}' \
  HOST:PORT/convert/image > output.jpg

# Widescreen 16:9
curl -F "file=@input.jpg" -F 'config={"format":"jpg","crop":{"aspectRatio":"16:9"}}' \
  HOST:PORT/convert/image > output.jpg

# Stories/Reels 9:16
curl -F "file=@input.jpg" -F 'config={"format":"jpg","crop":{"aspectRatio":"9:16"}}' \
  HOST:PORT/convert/image > output.jpg

22. Combinando várias configurações na mesma requisição

curl -F "file=@input.jpg" -F "watermark=@logo.png" \
  -F 'config={
    "format": "jpg",
    "crop": { "aspectRatio": "1:1" },
    "resize": { "maxWidth": 1080 },
    "rotation": 90,
    "watermark": { "position": "bottom-right", "size": 15, "opacity": 0.8 },
    "compression": { "maxSize": "500KB" }
  }' \
  HOST:PORT/convert/image > output.jpg

Fonte: URL remota (JSON, sem upload)

curl \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/input.png","format":"webp"}' \
  HOST:PORT/convert/image > output.webp
Parâmetros globais

Por padrão, o arquivo gerado é apagado do servidor após o download. Para manter, use ?delete=no em qualquer endpoint de download.

curl -F "video=@input.mov" HOST:PORT/convert/video?delete=no > output.mp4

Formatos suportados

O FFmpeg suporta praticamente todos os formatos de mídia. Consulte a lista oficial para detalhes.

Exemplos de entrada aceitos: .mov, .avi, .mkv, .mp4, .m4a, .wav, .mp3, .flac, .ogg, .webm, .png, .jpg, .tiff, .webp, .bmp e muitos outros.
