ffmpeg-api

Serviço HTTP para converter, extrair e processar arquivos de áudio, vídeo e imagem usando FFmpeg.

Endpoints

POST /probe Inspecionar metadados de arquivo de mídia ▸

Retorna os metadados completos do arquivo — equivalente a ffprobe -of json -show_streams -show_format. Funciona com qualquer formato de mídia.

Exemplo
curl -F "file=@input.mov" HOST:PORT/probe

Resposta: JSON com streams e formato do arquivo.

POST /convert/audio/to/mp3 Converte áudio para MP3 ▸

Codec: libmp3lame

Exemplos
curl -F "file=@input.wav" HOST:PORT/convert/audio/to/mp3 > output.mp3
curl -F "file=@input.m4a" HOST:PORT/convert/audio/to/mp3 > output.mp3
POST /convert/audio/to/wav Converte áudio para WAV ▸

Codec: pcm_s16le

Exemplos
curl -F "file=@input.mp3" HOST:PORT/convert/audio/to/wav > output.wav
curl -F "file=@input.m4a" HOST:PORT/convert/audio/to/wav > output.wav
POST /convert/video/to/mp4 Converte vídeo para MP4 ▸

Codec: libx264 · CRF 18 · preset medium · áudio libfdk_aac 192k · mantém resolução e framerate originais.

Exemplos
curl -F "file=@input.mov" HOST:PORT/convert/video/to/mp4 > output.mp4
curl -F "file=@input.avi" HOST:PORT/convert/video/to/mp4 > output.mp4
curl -F "file=@input.mkv" HOST:PORT/convert/video/to/mp4 > output.mp4
POST /convert/image/to/jpg Converte imagem para JPG ▸
Exemplos
curl -F "file=@input.png"  HOST:PORT/convert/image/to/jpg > output.jpg
curl -F "file=@input.tiff" HOST:PORT/convert/image/to/jpg > output.jpg
curl -F "file=@input.webp" HOST:PORT/convert/image/to/jpg > output.jpg
POST /video/extract/audio Extrai faixa de áudio de um vídeo ▸

Retorna WAV mono por padrão.

Query params
ParamValoresPadrãoDescrição
monoyes / noyesno retorna todos os canais do original
Exemplos
# Mono (padrão)
curl -F "file=@input.mov" HOST:PORT/video/extract/audio > output.wav

# Todos os canais
curl -F "file=@input.mov" HOST:PORT/video/extract/audio?mono=no > output.wav
POST /video/extract/images Extrai frames de um vídeo como PNG ▸

Extrai frames do vídeo como PNG. Sem compressão, retorna JSON com URLs para download individual.

Query params
ParamValoresPadrãoDescrição
fpsnúmero1Frames por segundo a extrair (0.5 = 1 frame a cada 2s)
compresszip / gzip—Retorna todos os frames num único arquivo compactado
Exemplos
# 1 frame por segundo — retorna JSON com URLs
curl -F "file=@input.mp4" HOST:PORT/video/extract/images

# 2 frames por segundo
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?fps=2

# 1 frame a cada 2 segundos
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?fps=0.5

# ZIP com todos os frames
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?compress=zip > frames.zip

# tar.gz com todos os frames
curl -F "file=@input.mp4" HOST:PORT/video/extract/images?compress=gzip > frames.tar.gz
Resposta JSON (sem compressão)
{
  "totalfiles": 3,
  "description": "Extracted image files and URLs to download them...",
  "files": [
    { "name": "abc123-0001.png", "url": "http://HOST:PORT/video/extract/download/abc123-0001.png" },
    { "name": "abc123-0002.png", "url": "http://HOST:PORT/video/extract/download/abc123-0002.png" }
  ]
}
GET /video/extract/download/:filename Baixa um frame extraído ▸

Baixa um frame extraído por /video/extract/images e o apaga do servidor por padrão.

Query params
ParamValoresPadrãoDescrição
deleteyes / noyesno mantém o arquivo no servidor após o download
Exemplos
# Baixa e apaga
curl HOST:PORT/video/extract/download/abc123-0001.png > frame.png

# Baixa sem apagar
curl HOST:PORT/video/extract/download/abc123-0001.png?delete=no > frame.png
POST /image/to/scroll-video Gera vídeo de scroll a partir de uma imagem longa ▸

Recebe uma imagem longa (ex: screenshot de página web), escala para a largura alvo e gera um vídeo MP4 com scroll suave de cima para baixo.

Query params
ParamPadrãoDescrição
velocidade180Velocidade do scroll em pixels/segundo
crf20Qualidade do vídeo: 0 = perfeito, 51 = pior
largura1080Largura do vídeo de saída em pixels
altura1920Altura da tela (viewport) em pixels
fps30Frames por segundo
Como funciona
  1. A imagem é redimensionada para a largura alvo mantendo a proporção.
  2. O percurso é calculado: altura_escalada − altura_tela.
  3. A duração é calculada: percurso / velocidade.
  4. O vídeo é gerado com um crop animado que percorre a imagem de cima a baixo.
Imagens com altura menor que a tela resultam em vídeo muito curto (percurso mínimo = 1px).
Exemplos
# Defaults (1080×1920, scroll 180px/s, CRF 20)
curl -F "file=@foto.jpg" HOST:PORT/image/to/scroll-video > scroll.mp4

# Scroll mais lento, qualidade máxima
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?velocidade=80&crf=15" > scroll.mp4

# 9:16 personalizado, 60fps
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?largura=1080&altura=1920&fps=60" > scroll.mp4

# Scroll rápido para preview
curl -F "file=@foto.jpg" "HOST:PORT/image/to/scroll-video?velocidade=400&crf=28" > preview.mp4
POST /image/to/images-to-video Cria vídeo a partir de múltiplas imagens ▸

Recebe N imagens via multipart/form-data (campo file repetido) e gera um vídeo MP4 onde cada imagem é exibida por igual tempo, totalizando exatamente totalDuration segundos.

Query params
ParamObrigatórioPadrãoDescrição
totalDurationsim—Duração total do vídeo em segundos
widthnão1920Largura em pixels
heightnão1080Altura em pixels
fpsnão30Frames por segundo
crfnão20Qualidade: 0 = perfeito, 51 = pior
scalenãocontainModo de ajuste da imagem (ver abaixo)
transitionnãofalsetrue adiciona fade suave entre imagens
Modos de escala
ValorComportamento
containImagem inteira visível com barras pretas nas bordas
coverImagem preenche o frame, pode cortar bordas
stretchImagem esticada para preencher exatamente (distorce)
fillImagem contida centralizada sobre fundo igual borrado (blur)
Lógica de tempo:
Sem transição: tempoPorImagem = totalDuration / N
Com transição: tempoPorImagem = (totalDuration + (N−1) × 0.5) / N
Limite: até 50 imagens por requisição. Tamanho máximo total: 512 MB.
Exemplos
# 5 imagens, 30s, 1080p, contain, sem transição
curl \
  -F "file=@img1.jpg" -F "file=@img2.jpg" -F "file=@img3.jpg" \
  -F "file=@img4.jpg" -F "file=@img5.jpg" \
  "HOST:PORT/image/to/images-to-video?totalDuration=30&width=1920&height=1080" \
  > slideshow.mp4

# 4 imagens, 20s, 9:16 (reels), cover, com fade
curl \
  -F "file=@img1.jpg" -F "file=@img2.jpg" -F "file=@img3.jpg" -F "file=@img4.jpg" \
  "HOST:PORT/image/to/images-to-video?totalDuration=20&width=1080&height=1920&scale=cover&transition=true" \
  > reel.mp4

# 3 imagens, fundo borrado, alta qualidade
curl \
  -F "file=@img1.png" -F "file=@img2.png" -F "file=@img3.png" \
  "HOST:PORT/image/to/images-to-video?totalDuration=15&scale=fill&crf=15&transition=true" \
  > video.mp4

wordsPerLine — Palavras por tela

Controla quantas palavras aparecem por bloco de legenda. Útil quando o arquivo de entrada tem muitas palavras por linha.

ValorComportamento
0 ou omitidoSistema decide (comportamento padrão, sem divisão)
1Uma palavra por vez
4Máximo 4 palavras por bloco
NMáximo N palavras por bloco
Para arquivos ASS com karaoke (\k tags): o tempo de cada grupo é recalculado com base na duração real das sílabas — o karaoke continua preciso. Para SRT e texto puro: o tempo do bloco original é distribuído proporcionalmente.
ASS sem estilos — configuração automática

Quando o arquivo .ass não possui uma seção [V4+ Styles], a API injeta automaticamente o estilo gerado a partir do config do request.

Isso permite manter o arquivo .ass com apenas os timings e tags de karaoke, delegando toda a aparência visual ao config.

Chave karaokeEfeito no estilo ASS
karaoke.textColorCor do texto ainda não falado (SecondaryColour)
karaoke.highlightColorCor da palavra ativa no momento (PrimaryColour)
Se o .ass já tiver [V4+ Styles], ele é usado diretamente sem modificação.

Exemplos

Burn simples com SRT

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.srt" \
  "HOST:PORT/subtitle/ass" \
  > output.mp4

Burn com estilo personalizado e efeito fade

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.srt" \
  -F 'config={"mode":"burn","style":{"fontsize":72,"primaryColor":"#FFFF00","outlineColor":"#000000","outline":3,"marginV":100},"effects":{"preset":"fade"},"animation":{"duration":300}}' \
  "HOST:PORT/subtitle/ass" \
  > output.mp4

ASS com karaoke pré-definido + cores via config

Envie um .ass que já tem os timings e tags \k, mas sem [V4+ Styles]. A API injeta o estilo do config automaticamente.

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.ass" \
  -F 'config={
    "mode": "burn",
    "style": { "fontname": "Bebas Neue", "fontsize": 60, "marginV": 150 },
    "effects": { "preset": "fade" },
    "animation": { "duration": 250 },
    "karaoke": { "enabled": false, "highlightColor": "#FFFF00", "textColor": "#FFFFFF" }
  }' \
  "HOST:PORT/subtitle/ass" \
  > output.mp4

Config completa com posição manual (vídeo vertical)

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.srt" \
  -F 'config={
    "mode": "burn",
    "playResX": 1080,
    "playResY": 1920,
    "wordsPerLine": 4,
    "style": {
      "fontname": "Bebas Neue",
      "fontsize": 60,
      "primaryColor": "#FFFFFF",
      "outlineColor": "#000000",
      "shadowColor":  "#000000",
      "backColor":    "#000000",
      "primaryAlpha": 0,
      "outlineAlpha": 0,
      "shadowAlpha":  0,
      "backAlpha":    0.5,
      "bold": false,
      "outline": 2,
      "shadow": 1,
      "position": { "x": 540, "y": 1400 }
    },
    "effects":   { "preset": "fade" },
    "animation": { "duration": 250, "intensity": 1.0, "delay": 0 },
    "karaoke":   { "enabled": false, "highlightColor": "#FFFF00", "textColor": "#FFFFFF" },
    "output":    { "crf": 20, "preset": "medium", "threads": 8 }
  }' \
  "HOST:PORT/subtitle/ass" \
  > output.mp4
x: 540 = centro horizontal de um vídeo 1080px.  y: 1400 = ~73% de altura em um vídeo 1920px.

wordsPerLine — dividir legenda em grupos de palavras

# SRT com máximo 4 palavras por bloco
curl \
  -F "video=@video.mp4" \

# ASS com karaoke, agrupando de 5 em 5 palavras
curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda_karaoke.ass" \

  "HOST:PORT/subtitle/ass" \

Karaoke com SRT (API adiciona \k automaticamente)

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.srt" \
  -F 'config={"karaoke":{"enabled":true,"mode":"kf","highlightColor":"#FFFF00","textColor":"#FFFFFF"},"effects":{"preset":"fade"}}' \
  "HOST:PORT/subtitle/ass" \
  > output.mp4

Texto puro (geração automática de timing)

curl \
  -F "video=@video.mp4" \
  -F "transcript=Primeira parte do texto" \
  -F 'config={"style":{"fontsize":60},"effects":{"preset":"slide-left"}}' \
  "HOST:PORT/subtitle/ass" \
  > output.mp4

Soft subtitle (faixa separada, sem re-encode)

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.ass" \
  -F 'config={"mode":"soft"}' \
  "HOST:PORT/subtitle/ass" \
  > output.mkv

Fonte customizada

curl \
  -F "video=@video.mp4" \
  -F "subtitle=@legenda.srt" \

Parâmetros globais

Por padrão, o arquivo gerado é apagado do servidor após o download. Para manter, use ?delete=no em qualquer endpoint de download.

curl -F "file=@input.mov" HOST:PORT/convert/video/to/mp4?delete=no > output.mp4

Formatos suportados

O FFmpeg suporta praticamente todos os formatos de mídia. Consulte a lista oficial para detalhes.

Exemplos de entrada aceitos: .mov, .avi, .mkv, .mp4, .m4a, .wav, .mp3, .flac, .ogg, .webm, .png, .jpg, .tiff, .webp, .bmp e muitos outros.
