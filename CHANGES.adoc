=== 0.5 (2026-08-21)

* Replaced `POST /convert/audio/to/mp3` and `POST /convert/audio/to/wav` with `POST /convert/audio`: converts any FFmpeg-supported audio input to any supported output format (`mp3`, `wav`, `aac`, `m4a`, `flac`, `ogg`, `opus`, `wma`, `aiff`), with the same 4 input sources and request/response conventions as `POST /convert/video`.
* Added `quality.mode="default"/"reduce"/"maxSize"` on `POST /convert/audio`: no change by default, reduce bitrate by a percentage, or target a maximum output file size (MB) — reusing the same size-budget math as `video.quality.mode="maxSize"`.
* `resolution.orientation` on `POST /convert/video` now defaults to `"auto"` (detects portrait vs. landscape from the source) instead of always assuming landscape — a 9:16 source asking for `"720p"` now gets 720x1280 instead of being padded into 1280x720.

=== 0.4 (2026-08-20)

* Replaced `POST /convert/video/to/mp4` with `POST /convert/video`: full control over container, resolution/orientation/resize-mode/background, video codec/quality/preset/fps/color-space/HDR/rotation/flip, audio codec/bitrate/channels/sample-rate/removal, and metadata.
* Added `video.quality.mode="maxSize"`: targets a maximum output file size (MB) and computes the required video bitrate automatically from the source duration, instead of requiring a manual CRF/bitrate value.
* Added support for 4 input sources on `POST /convert/video`: multipart upload, base64, remote URL, and local file (shared `uploads/` volume).
* Fixed the `uploads/` Docker volume mount, which previously pointed at a path outside the running container's working directory.

=== 0.3 (2026-06-29)

* Added `POST /video/add/audio`: mix or attach up to 5 audio tracks onto a video, with per-track volume/trim/delay/loop/fade/playback-rate, ducking, crossfade, normalization, and `afterVideo` extensions (freeze/color/image) when audio outlasts the video.

=== 0.2 (2026-06-28)

* Added `POST /image/to/scroll-video`: generates a smooth scrolling video from a tall image (e.g. a webpage screenshot).
* Added `POST /image/to/images-to-video`: builds a slideshow video from multiple images with configurable scaling and transitions.
* Added `POST /subtitle/ass`: burns or soft-attaches subtitles (ASS/SRT/plain text) with full styling, animated effects, and karaoke highlighting.
* Added bundled fonts (Bebas Neue, Open Sans) and custom font upload support for `/subtitle/ass`.
* Rewrote `/` into a rich, self-documenting HTML endpoint listing.
